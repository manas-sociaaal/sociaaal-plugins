# Rizz God — Research Dossier

## App at a glance
AI pickup line generator. Give it a context (or a screenshot of a dating app message), get clever opening lines back. Text-AI category. Light-medium AI fit — chat screen mockups + simple zooms.

## Audience profile
- **Primary:** Single Gen Z guys (18–25) using dating apps (Hinge, Bumble, Tinder), single Gen Z girls in lower numbers.
- **Secondary:** Content creators making dating-humor content, friend groups doing "rate my rizz" challenges.
- **Where they live:** TikTok #rizz / #datingapps / #pickuplines, Instagram dating-humor pages, Twitter/X dating-app screenshot threads.
- **Motivation:** Never run out of opening lines. Save face when you don't know what to say. Get more matches / responses.

## Core promise
**Never run out of clever opening lines.**

## Value props (ranked)
1. Context-aware lines (input the situation, get tailored output)
2. Variety — humor, sincere, edgy, smooth options
3. Speed — 5 seconds from context to lines
4. Shareable for "Use this line" creator content

## Format playbook
**Works:** dating-app screen recording, POV girl-reading-text, talking-head "use this line" format, before-after match-rate reveals.
**Doesn't:** sincere/dramatic tone (audience is humor-coded), purely visual / wordless storytelling.
**AI-asset fit:** Light to medium — chat screen mockups via NanoBanana (Hinge / Bumble / Tinder UI mockups), simple zoom and tap motion via Kling.

## Competitor context
Differentiate from generic ChatGPT-as-rizz (same output but no curated UI), Hinge's built-in prompt suggestions (limited), older Tinder-line generators. Rizz God's lane is the **dedicated mobile UX with curated humor / sincere / edgy options**.

## Don't-do list
- **Avoid creepy / harassing line styles** — even ironically. The line bank must respect consent.
- Avoid showing real dating-app screenshots with real names — use mockups or blurred names.
- Don't position as "manipulating women" — that's both gross and a brand-safety risk on platforms.
- Be cautious with the female-targeted angle — most messaging assumes male user.
