# Fontmaker — Research Dossier

## App at a glance
Custom font keyboard for iOS. Aesthetic, handwriting, and novelty fonts available in any app. Keyboard-aesthetic category. Screen-first product — most demonstration is screen recording.

## Audience profile
- **Primary:** Gen Z teen girls (14–22), aesthetic-driven users, social bio decorators, students who decorate notes.
- **Secondary:** Beauty / lifestyle creators wanting "branded" text, anyone with an Instagram bio.
- **Where they live:** TikTok #aestheticfont / #iphonekeyboardhack, Instagram bio communities, Pinterest aesthetic boards, Tumblr-coded users.
- **Motivation:** Aesthetic self-expression. Standing out in default Helvetica. Making a bio feel "main-character-coded."

## Core promise
**Make every text, post, and bio look styled — never default Helvetica.**

## Value props (ranked)
1. Hundreds of fonts including handwritten, aesthetic, decorative, novelty
2. Works in ANY app (Messages, Instagram bio, Discord, Notes)
3. One-tap insert — no copy-paste
4. Aesthetic library updates regularly

## Cultural moments to ride
- Aesthetic seasons (Y2K revival, coquette, soft girl, clean girl, dark academia, etc.)
- Bio aesthetic trends (specific symbol combos go viral cyclically)
- Back-to-school season (notes, planners, study aesthetics)
- TikTok "POV: I just got this app" reveal trends

## Format playbook
**Works:** screen-recording text transformation, before/after typography, "POV I just got this app" reveals, study-aesthetic content with the keyboard featured.
**Doesn't:** complex live action — this is a screen-first app.
**AI-asset fit:** Light. Most shots are real screen recordings. AI used for B-roll mood (aesthetic backgrounds, vibe footage of journals/desks/coffee/study setups).

## Competitor context
Differentiate from Fontkey (sister app, more emoji-focused — see fontkey.md), Fonts AI Keyboard (similar feature set), Cool Fonts (free competitor). Fontmaker's lane is the **broad aesthetic font library with strong UI**.

## Don't-do list
- Don't promise font support in apps where iOS keyboard custom fonts don't render (e.g. some games — frame as "where it works").
- Don't oversell — fonts are Unicode tricks, not actual installed system fonts.
- Avoid screen-recording with notification banners visible.
