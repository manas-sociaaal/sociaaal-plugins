# Litstick — Research Dossier

## App at a glance
AI stickers + reactions library for iMessage. Custom sticker generator + meme/reaction sticker library. Stickers-social category. iMessage-first product — screen recording of chats is the main demo surface.

## Audience profile
- **Primary:** iMessage power-users (US/UK/CA), Gen Z friend groups, meme curators in chat groups.
- **Secondary:** Late millennials in heavy group-chat culture, content creators making chat-screenshot content.
- **Where they live:** TikTok #imessage / #stickers / #imessagestickers, Instagram Reels chat-screenshot content, friend-group chats themselves.
- **Motivation:** Have the perfect reaction sticker for every moment. Inside jokes turned into stickers.

## Core promise
**The perfect sticker for every reaction or inside joke.**

## Value props (ranked)
1. Massive curated sticker library (memes, reactions, celebrities, niche)
2. AI-generate a custom sticker on demand
3. Direct iMessage integration — one tap, in any chat
4. Updates with current memes weekly

## Past creative observations
- P0_X folder in `NEW PHASE GATE/LITSTICK/`. (Review on next run.)
- Likely formats: iMessage screen recording with sticker-spam reveals, "before/after" text-conversation glow-ups, reaction-pack drop announcements.

## Cultural moments to ride
- Trending memes (the half-life is 1–4 weeks — react fast)
- Celebrity moments turned into reaction images
- Holiday/seasonal sticker pack drops
- "iMessage glow up" / "your texts are boring" trends
- Specific show or movie meme cycles (e.g. Love Island moments, reality TV meltdowns)

## Format playbook
**Works:** iMessage screen recording with sticker reveals, sticker explosion / collage motion, before-after text conversation glow-up.
**Doesn't:** realistic human footage — this is a chat / sticker product.
**AI-asset fit:** Strong for sticker concept stills. Motion clips show stickers floating/popping into a chat.

## Competitor context
Differentiate from Bitmoji (Snapchat-locked, avatar-based), Sticker.ly (free but ads-heavy, web-export oriented), Tenor GIF keyboard (animated, not stickers). Litstick's lane is the **best-curated iMessage sticker library + AI generation**.

## Don't-do list
- Stickers must respect celebrity right-of-publicity — don't ship celebrity stickers without licensing (use vibe-alikes if needed).
- Avoid stickers that punch down or could be flagged (slurs, harassment-coded).
- Don't show fake iMessage threads that imply real conversations with named people.

## Open research questions
- AI-custom-sticker generation vs library browse — which drives more retention?
- Friend-pair sticker drops (couple stickers, BFF stickers) — is that lane open?
- Cross-platform expansion (Discord, WhatsApp) — would TikTok content for those drive iOS installs anyway?
